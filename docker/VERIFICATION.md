- 相对当前主分支基线的交付差异仅保留 `docker/`；目录外的 Rust 脚本、四份文档恢复主分支版本，移除本分支新增的目录外测试，不重写已推送历史。
- [Docker Rust 入口](<build-rust.sh>)为 86 行 Linux 专用构建流程，工具链在镜像中预装，不再运行宿主项目的通用安装脚本。移除新增的源码 SHA、原子下载发布、安全删除框架、额外 ECH 头检查、跨平台探测与通用参数处理。
- 保留上游原有 `no-shared` 编译参数和线程检查/缓存标记，以及避免修改锁文件的 Cargo `--locked`；不影响 ADB 防误操作或容器权限隔离。

### 当时方案：仅 adb reverse

- 保留 `network_mode: host`、宿主 ADB server 和原有缓存布局；不提供 LAN 自动选路或双模式。
